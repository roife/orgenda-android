# 0.1.3 功能对齐补充

本轮延续 [UI 组件清单](UI_COMPONENTS.md)，核对真实操作和数据提交时序，保留 Material 原生组件。修改位于 main，未运行格式化工具，未修改 iOS。0.1.2 安装包与 [验收记录](ACCEPTANCE-0.1.2.md) 独立保留。

## 新增与修复

| 行为 | 0.1.2 差异 | 0.1.3 处理及边界 |
|---|---|---|
| 设置中的模板与状态保存 | 点保存即关闭，稍后自动保存失败只能在设置页恢复 | 模态表单等待本地事务提交，期间禁用输入、重复提交和关闭；失败保留草稿并可重试。候选配置成功前不发布到全局自动保存队列。工作区及配置基线变化时拒绝覆盖；旋转重放已成功的同一候选不会重复写入。 |
| 文件移动 | 点移动即关闭，失败丢失当前操作上下文 | 等待本地移动提交后关闭；失败留在表单，保留名称与目标目录；处理中显示进度并禁用重复操作。远端同步继续采用 Android 既有持久队列。 |
| 文件夹浏览位置 | 共用列表滚动状态，进入深层目录和返回时位置混用 | 按工作区和目录分别保存列表位置，新目录从顶部开始，返回恢复父目录位置。 |
| 回收站文件夹 | 文件夹及每个后代都出现独立恢复入口 | 根据真实物理路径和待执行删除操作显示删除根项；保留独立删除、不同回收桶以及缺少根项的孤立文件，不按原路径或相同时间猜测归属。 |
| 源码撤销 | 连续输入逐字符撤销；输入法结束组合后撤销状态更新不足 | 连续输入按段分组，选择、命令和暂停输入切组；输入法提交后可直接撤销；工具栏插入仍是独立一步。 |
| 插入日期的选区 | 打开日期选择后旋转，原选区可能变成恢复后的阅读光标 | 保存打开时的 UTF-16 选区及原文哈希；重建后按原选区插入。正文被替换时禁用插入并提示重新选择位置。 |
| 大纲移动和筛选 | 移到新父节点后展开 key 改变，子树隐藏；旋转丢失筛选 | ViewModel 发布旧 key 到新 key 的明确映射，保留展开路径并展开新祖先；筛选、展开及已处理移动保存实例状态；处理文档先更新、映射后到达的时序。 |
| 撤销与外部正文更新 | 外部同步替换文本后，旧 Undo 可能写回旧正文 | 历史绑定对应正文；外部文本不匹配时清除 Undo/Redo，同正文重建保留。预览操作后的源码历史也保守重置，详见剩余差异。 |
| 日期与时区变化 | 页面静止时 LocalDate.now 不会触发重组，逾期和“今天”可能停留在昨日 | 根级单一日期状态监听日期/时间/时区广播、恢复前台和下一本地午夜；按实际时区计算，包括夏令时 23/25 小时日。Dashboard、逾期、日历、Habit 与时间线索引共同更新，同时保留用户正在浏览的日期。 |

## iOS 对照依据

- `Features/Settings/ConfigurationEditors.swift`：模板及工作流编辑的保存中状态、等待保存、错误与取消。
- `Features/Files/WorkspaceFileActions.swift`、`WorkspaceBrowser.swift`：移动表单、最近删除和目录导航。
- `Components/Editor/OrgSyntaxTextEditor.swift`：输入撤销分组、外部 revision 与本地编辑历史。
- `Components/Editor/OrgEditorSession.swift`：打开日期选择时固定编辑选区。
- `Features/Files/Document/DocumentOutline.swift`：标题移动后的展开映射和目标祖先。
- 日期刷新属于实际使用缺口修复：iOS 的前台刷新和 Date.now 不能证明其所有午夜缓存都能自动刷新；本轮没有把 iOS 的潜在缓存问题当作需要复制的行为。

## 验证与剩余差异

本轮增加配置事务失败/重试/旧基线/旧工作区/幂等重放、表单失败与旋转、文件目录导航、回收站分组、编辑历史、日期选区、大纲连续性，以及日期时区变化的单元和设备测试。完整执行数量及结果见 [当前验收](ACCEPTANCE.md)。

Android 尚未将所有预览中的复选框、状态等领域修改纳入同一源码撤销栈。可靠区分本会话修改与外部同步需要单独的来源追踪；本轮正文改变后保守清除旧历史，避免将旧快照写回新正文。大纲仍显示工作流原始 token；收起键盘后从大纲跳转会定位光标，但不自动弹出键盘，详见 [文档专项剩余差异](ui-parity-document.md)。真机 TalkBack、真实输入法、实际云账户、厂商后台行为等验证边界仍保留。
