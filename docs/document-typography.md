# 文档预览字体层级

以欢迎文档截图为基线，按对比、重复、对齐、亲密性调整现有原生预览。

| 角色 | 字号 | 字重 |
| --- | --- | --- |
| 文档标题 | 26 sp，32 sp 行高 | Bold |
| 一级分组 | 20 sp | SemiBold |
| 二级分组 | 18 sp | SemiBold |
| 更深分组 | 16 sp | SemiBold |
| 任务标题（所有层级） | 16 sp | Medium |
| 作者、启动属性、任务标签 | 13 sp，18 sp 行高 | Normal |

- **对比**：文档标题是主要入口；分组通过字号和字重建立层级；任务标题采用独立文字角色，避免一级任务与一级分组竞争。正文沿用 17 sp。
- **重复**：`DocumentTypography` 集中定义文字角色，富文本与纯文本标题共用字号和字重。层级较深时继续用缩进表达结构。
- **对齐**：任务标题和标签共用同一文字列；原有层级缩进、正文与习惯记录的起点保持一致。折叠与状态控件根据实际字体度量，共享标题首行基线；不再使用固定顶部偏移。
- **亲密性**：标签位于标题下方 2 dp，同属一个文字组；各级标题前间距统一为 10 dp，略大于正文段落的 8 dp，另保留列表本身的 2 dp 间隔。去掉标题文字列原有的上下 8 dp 留白；折叠和状态控件使用 24 dp 可见高度，并沿用 Compose 扩展触控区域，避免控件空白撑大标题行。

所有字号仍使用 sp，允许随系统设置放大和自然换行。任务状态颜色沿用工作流配置。该改动不改变源文档、任务状态转换或正文编辑字号。

验证包括 392 dp 普通字号与 320 dp 两倍字号的截图及交互检查，以及既有习惯记录、正文对齐与抽屉回归。证据位于 `artifacts/document-typography/`；具体结果见根目录 `design-qa.md` 中的文档字体专项记录。
