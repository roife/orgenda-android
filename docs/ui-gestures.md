# 组件手势（2026-10-22）

参考 `~/.config/orgenda` 当前 iOS 源码的 `OrgItemRow.swift`、`WorkspaceFileActions.swift`、`OrgHeadingDrag.swift` 和 `OrgendaCalendarDayGrid.swift`，补齐 Android 组件的手势入口。按钮、菜单、无障碍操作和已有撤销流程继续可用。

以下左右方向以从左到右布局为例；RTL 布局自动交换两侧。

| 组件 | 操作 | 行为 |
| --- | --- | --- |
| 文件／文件夹行 | 右滑 | 显示置顶／取消置顶按钮，点按执行 |
| 文件／文件夹行 | 左滑 | 同时显示移动、删除按钮；移动进入现有目标选择界面，删除仍需确认 |
| 任务行 | 短距离右滑 | 显示完成／恢复未完成按钮 |
| 任务行 | 整行右滑 | 执行一次现有完成流程，需要日志备注时仍进入备注界面 |
| 任务行 | 左滑 | 同时显示改期和编辑；不能改期的事项仅显示编辑 |
| 文件／文件夹行 | 长按名称、图标或行内留白并拖到文件夹 | 移动文件或整棵目录；拖到顶部返回按钮移回上级，列表边缘自动滚动 |
| 日历任务 | 长按任务行或完成控件并拖到日期 | 使用现有改期流程，拖动不会切换完成状态或打开预览；预览保留在更多菜单中 |
| 预览标题 | 长按标题文字或行内留白，拖到另一标题 | 上部 25% 插到之前，下部 25% 插到之后，中部作为子标题；移动整棵子树，边缘自动滚动 |
| 大纲标题 | 长按标题行后拖到另一标题 | 上部插到之前，下部插到之后，中部作为子标题，移动整棵子树；拖至列表边缘自动滚动，普通点按仍跳转正文 |

文件两侧、任务左侧均不会因整行滑动直接执行操作。展开另一行会收起上一行；点按已滑开的正文、在该行开始纵向滚动或返回键可收起按钮。临时展开状态不跨页面或进程恢复。日历时间线继续禁用行横滑，以保留日历翻页手势。

`SwipeActions.kt` 使用 Compose 横向拖动与停靠点，按松手时的实际位移决定展开或完成，避免短距离快速滑动被惯性判成完成。取消手势回到关闭状态。新按钮带文本和按钮语义；原有菜单和无障碍操作保留。

标题拖放在移动过程中显示插入线，中部另有子标题背景提示。拖放携带编辑会话和原始标题快照，拒绝自身、子树内部、其他文档、其他会话或源哈希已变化的目标；松手前再次校验。预览和大纲均移除专用拖动把手，通过无障碍自定义操作提供上移、下移、缩进、减少缩进；预览标题仍可点按编辑任务和状态。文件夹拖放也拒绝自身、后代、原目录及过期文件状态，文件更多菜单与两侧滑动操作保留。

预览标题的原生 TextView 与 Compose 标题行使用同一种本地拖放载荷，长按标题文字不再打开编辑器或启动文本选择。正文仍可选择，标题中的链接仍可点击。预览列表统一接收标题落点，覆盖缩进留白、正文和末尾空白；移动始终包含原有正文和子标题。文件拖放改变目录位置；“全部文件”的文件夹优先／名称排序和“最近”的打开时间排序保持各自规则。

文件列表也统一接收落点，并在松手时解析当前可见目录，避免自动滚动后才出现的文件夹漏接拖放。拖到顶部返回按钮可移回上级，目标目录或返回按钮以主题容器色提示。目录创建／移动继续使用既有文件操作队列与冲突保护。
